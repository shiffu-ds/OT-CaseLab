# Dataset cards

Updated 1 October 2026.

## Original demo corpus

`data/demo/cases.json`: five fictional adults; two stroke scenarios, one hand injury, and two home/work participation scenarios. Thirty facts each include English, Urdu script and Roman Urdu. Four original rubric dimensions per case, two reused original CC0 schematic assets and their authored draft annotations. Asset boxes are normalized `xywh` relative to the SVG viewbox 1000×650. No actual patient/learner records or demographic inference is included.

Purpose: reproducible interface, API, scripted dialogue and security demonstration. Review: **all cases, rubrics and annotations pending educator review; all original reference notes unapproved at seed**. Licence/origin: [demo manifest](../data/demo/LICENSE_MANIFEST.json), CC0-1.0. Generation source: `data/demo/build_cases.py`. English/Urdu/Roman Urdu translations are original drafts and may contain errors. The corpus is not a validated clinical teaching resource or gold-standard NLP/CV dataset.

## Authored NLP regression fixtures

Seven small implementation examples in `ai/evaluate.py` with intentionally specified expected mentions. No independent educational review; no population sampling or fairness inference. A perfect result on these examples is an implementation regression outcome only. See `ml/reports/nlp-baseline-regression.json`.

## Synthetic recommendation fixtures

Generated by `ml/train.py --synthetic`: 432 rows across 144 invented learners and 12 case groups, three historical rows per fictional learner. Labels are generated from prior-score mechanics, not next-attempt educator outcomes. Split manifest separates case and learner identities (324 train / 108 test in the recorded run). Purpose: run preprocessing, fit, numeric-artifact serialization, split checks and baseline comparison. Not permitted as a validated predictor for real students. Deployed recommendation remains the rule baseline.

## Missing research datasets

Consented longitudinal real learner trajectories, independent expert ratings, representative licensed staged photos, adjudicated multilingual spans, retrieval relevance judgments and study participants are **not collected**. Suitable collection, review and separate pilot/train/validation/test manifests are required. Schematics are not a substitute for natural-image validation. No real-learning or national-curriculum claim is supported by these demo/synthetic data.
