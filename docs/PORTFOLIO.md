## Four-minute fictional demonstration

1. Sign in as a student and show the provider mode and pending-review notice. Select **Ayesha: choosing a dressing routine**. Explain that the person and content are original drafts.
2. Ask which activity matters most, how the routine works and what assistance is preferred. Ask an unknown measurement/restriction question and show that the patient leaves it unknown.
3. Describe the room independently. Identify chair/shelf/table without claiming measured accessibility. If using assistance, show the distinction between original draft annotations and actual provisional neural proposals.
4. Write a profile, patient-prioritized goal, environmental observations and reasoned educational plan; record missing information. Submit and open exact learner excerpts, original rubric mapping, source status and transparent next-practice recommendation.
5. Sign in as educator and add an amendment with a reason. Return to the learner to show the preserved original report and attributed amendment. Export the owned Markdown report.
6. Show one recorded MCP initialization/tool trace and model smoke report. State the Roman Urdu neural abstention and schematic detector failure, then explain the missing expert data, provider test and live deployment gates.

## Research proposal abstract

**Status: proposed study, no findings.** OT education requires practice connecting a person's occupational priorities to context and functional goals. OTCaseLab is a fictional adult rehabilitation trainer with multilingual interviewing, supplied environment images and provisional feedback linked to learner excerpts. A proposed study would compare matched static/general-purpose AI workflows and isolate image reasoning, grounded feedback, recommendation and orchestration features. Independent educators would rate unseen transfer tasks and multilingual equivalence, using consented records, frozen splits and predeclared measures. Outcomes would include transfer-task performance, feedback corrections, unsupported claims, usability and actual resource cost. Content review, institutional research determination and suitable labelled data precede recruitment. The intended contribution is an evaluated educational workflow; no clinical efficacy or national novelty is claimed.
